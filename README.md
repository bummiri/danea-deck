# DANEA 서비스 소개서

비밀번호로 잠긴 열람 페이지입니다.

- 주소 : https://bummiri.github.io/danea-deck/
- 본문은 AES-256-GCM 으로 잠겨 있고, 비밀번호에서 뽑은 열쇠로만 풀립니다.
  비밀번호가 틀리면 복호화 자체가 실패합니다. 평문은 저장소 어디에도 없습니다.
- 흰색 판본으로 고정되어 있어, 보는 사람의 기기가 어두운 모드여도 흰 화면으로 열립니다.

| 파일 | 하는 일 |
|---|---|
| `index.html` | 비밀번호 화면 |
| `deck.enc` | 잠긴 소개서 본문 |
| `logo.png` | 로고 |

다시 만들 때 : `소개서/mk_gh.py` 를 돌리고 `_gh/` 안의 세 파일을 올립니다.
